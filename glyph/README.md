# glyph shell (quickshell)

The desktop shell: top bar, home screen with the development widgets, quick settings, launcher, settings,
notifications, lock screen. It is based on [glyph-rice](https://github.com/Nebelung-cloud/glyph-rice) (GPL-3.0, see `LICENSE`)
and is kept here with all local changes, so a new machine gets exactly this setup.

Everything is **symlinked**, so editing the live files edits this repo, and the settings you change in the shell
(`Super+T`) are saved straight into it.

## Install on a new machine

`./install.sh` from the repo root does everything (packages in step 04, links in steps 06 and 06b).
Only the shell: `scripts/06b-glyph.sh`. Then log in again (Hyprland starts the shell) or run `rice start`.

## What is where

| In the repo | Linked to | What it is |
|---|---|---|
| `glyph/quickshell/glyph/` | `~/.config/quickshell/glyph` | the shell (QML) |
| `glyph/quickshell/rice/` | `~/.config/quickshell/rice` | the switcher; `rice/rice` is the `rice` command (`~/.local/bin/rice`) |
| `glyph/fonts/` | *(not linked)* | Doto, Space Mono, Space Grotesk — kept here but not installed: with them the shell text rendered as garbled symbols. See `scripts/06b-glyph.sh` to try them |
| `glyph/qtengine/` | `~/.config/qtengine` | Qt theme settings |
| `glyph/state/` | `~/.local/state/rice` | **your settings**: `glyph.json` (home widgets, bar, colors, rounding, ...) and `shell` |
| `.config/glyph/` | `~/.config/glyph` | `dev-ignore`: projects hidden from the home widgets |
| `.config/demonshot/` | `~/.config/demonshot` | `rules.json`: monitor, input, idle, power rules |
| `packages.txt` | | the packages the shell needs (a `# glyph shell` block at the end) |

Folders are linked, not single files, on purpose: the shell saves a setting by writing a new file and renaming it over
the old one, which would replace a linked file but works inside a linked folder.

Not tracked (regenerated by the shell on start, see `.gitignore`): `glyph/state/glyph/` (copies of the theme files for
GTK/Qt), `.config/demonshot/hypridle.conf` and `wezterm.lua`.

## Things to know

- **Settings:** `glyph/state/glyph.json` also holds the unread-notification count and the wallpaper tones, so it changes a
  little on its own; that is normal.
- **Home widgets:** `projects`, `git`, `docker`, `ports`, `commits`, `heat`, `focus`, `launch`, `tools`, `prs` (and the original
  weather, calendar, cpu, ...). Pick them in the shell settings, section HOME. Their data comes from `services/Dev.qml`.
- **One size for all panels:** `uiScale` in `quickshell/glyph/Theme.qml`. The bar and the home screen ignore it.
- **Hyprland:** the binds that call the shell (`Super+O` quick settings, `Super+H` keybind cheatsheet, `Super+Ctrl+P` VPN, ...)
  are in `.config/hypr/lua/keybinds.lua`; the shell is started from `.config/hypr/lua/startup.lua`.
- **Restart the shell:** `rice restart` (or `Ctrl+Super+Alt+R`, bound in `.config/hypr/lua/keybinds.lua`). Brand-new QML files need a restart; edits to existing ones reload live.
- **Updating from upstream:** this is a vendored copy with local changes. To take upstream changes, diff against a fresh clone of
  glyph-rice by hand.
